# Resumo de Aprendizado: HTML

### O que é o HTML?

O **HTML (Hypertext Markup Language)** não é uma linguagem de programação, mas sim uma **linguagem de marcação**. Enquanto linguagens de programação lidam com lógica, funções e repetições, o HTML é utilizado para **estruturar e marcar os elementos de uma página web**, como títulos, imagens e parágrafos.

Ele funciona como o esqueleto do site, definindo onde cada peça de conteúdo deve ficar.

---

### Glossário de Tags Principais

As tags são a base da sintaxe do HTML e servem para indicar ao navegador o que cada parte do conteúdo representa.

- **`<h1>` a `<h6>`**: São tags de **título**, utilizadas para definir a hierarquia de importância do conteúdo. O `<h1>` representa o título principal e os demais representam subtítulos.
- **`<p>`**: Define um **parágrafo** de texto.
- **`<a>`**: Chamada de tag de **âncora**, é usada para criar **links** para outros sites ou páginas. Ela utiliza o atributo `href` para indicar o destino.
- **`<img>`**: Utilizada para inserir **imagens**. É uma tag que não possui fechamento e depende dos atributos `src` (caminho da imagem) e `alt` (texto alternativo para acessibilidade).
- **`<ul>` e `<ol>`**: Criam **listas**. A `<ul>` cria listas não ordenadas (com marcadores de ponto) e a `<ol>` cria listas ordenadas (numeradas).
- **`<li>`**: Define cada **item individual** dentro de uma lista (`<ul>` ou `<ol>`).
- **`<strong>` ou `<b>`**: Utilizadas para deixar o texto em **negrito**.
- **`<em>` ou `<i>`**: Utilizadas para deixar o texto em **itálico** (ênfase).
- **`<br>`**: Provoca uma **quebra de linha** simples no texto.

---

### Organização e Aninhamento com a Tag `<div>`

A tag **`<div>`** (abreviação de *division*) é fundamental para a **organização do código**. Ela funciona como um "container" ou uma caixa que agrupa diversos elementos dentro de uma mesma seção.

O uso da `<div>` facilita o **aninhamento (nesting)**, que é o ato de colocar um elemento dentro de outro. Isso permite que o desenvolvedor separe o site em blocos lógicos, como um cabeçalho, um corpo de conteúdo ou um rodapé, tornando o código mais legível para outros programadores e facilitando a aplicação de estilos visualmente mais tarde.
